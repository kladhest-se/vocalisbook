# VocalisBook 1.0.0

Initial source release of the Plex audiobook player for iPhone/iPad, Mac and Apple TV.

- Book-absolute progress, chapters, playback speed, sleep timer and bookmarks.
- Optional iCloud listening-state sync; offline downloads on iPhone and Mac.
- Platform-specific browsing and player interfaces.
- Correctness fixes for cloud acknowledgements, optional fields, server identities, session ownership and download lifecycle.
- GPL-3.0-or-later licensing, contributor documentation and regression checks.

This repository release supplies source, the PHP website package, provenance and checksums. App Store distribution and signed-device/live Plex/iCloud validation remain separate; availability is not implied by this release.
